## Contexto / problema

Os workflows originais restringem o push à main e não disponibilizam um relatório de cobertura como artefato para inspeção.

## Resultado esperado

Executar verificações em pushes de qualquer branch e em pull requests, preservando a base existente e disponibilizando cobertura de testes.

## Critérios de aceite

- [ ] Ajustar os gatilhos para push em todas as branches e pull_request.
- [ ] Manter instalação com npm ci, lint, build e testes com PostgreSQL disponível e configurado.
- [ ] Configurar geração de cobertura Vitest com dependência compatível com a versão adotada no projeto.
- [ ] Adicionar upload do relatório por uma GitHub Action referenciada via uses:, com versão suportada verificada na implementação.
- [ ] Garantir falha do workflow quando testes, lint ou build falharem; não mascarar falhas com continue-on-error.
- [ ] Documentar a melhoria e incluir no PR links de execução e evidência do artefato de cobertura.
